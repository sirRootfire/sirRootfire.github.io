Zero-Trust Production Linux Server Hardening

Security Hardening

Challenge: An internet-facing RHEL enterprise node experienced over 1,500 daily automated brute-force SSH attacks, with exposed unnecessary network ports and permissive default access.
Solution: Implemented CIS-benchmark hardening: enforced SELinux in targeted mode, reconfigured OpenSSH to accept only Ed25519 public keys on custom ports, structured segmented firewalld zones, and deployed Fail2ban jails with automatic IP banning. Verified all rules using Nmap and system audit logs.
Result: Reduced unauthorized connection attempts to zero, eliminated plain-text password vectors, and established full compliance with security best practices.

RHEL / Rocky Linux SELinux Enforcing Firewalld Fail2ban SSH Hardening

Automated Disaster Recovery & Btrfs/LVM Snapshot Pipeline

Automation & Storage

Challenge: A critical staging environment suffered from inconsistent manual backup practices, putting client configurations and database dumps at risk of corruption.
Solution: Engineered an automated Bash pipeline integrated with Btrfs snapshot management and Rsync. The workflow triggers atomic snapshots, creates GPG-encrypted tarballs, offloads archives to a remote backup destination, and cleans up older snapshots via an intelligent retention policy run by systemd timers.
Result: Achieved a verifiable 15-minute Recovery Time Objective (RTO) and successfully recovered system states during dry-run disaster drill tests without losing a single file.

Bash Scripting Btrfs Subvolumes GPG Encryption Systemd Timers Disaster Recovery

Isolated Multi-Container Web Architecture Deployment

Virtualization

Challenge: Client required migrating multiple independent PHP/Node web apps onto a single Linux VPS without package conflicts, port collisions, or privilege escalations.
Solution: Deployed rootless Podman/Docker containers orchestrated via Compose. Isolated each app into private software bridges, placed them behind a unified Nginx Reverse Proxy with automated SSL certificates, and locked down container resource limits via cgroups.
Result: Reduced server memory footprint by 35% compared to multi-VM configurations while providing complete tenant process isolation and zero-downtime service reboots.

Docker Compose Podman Rootless Nginx Reverse Proxy SSL/TLS Bridge Networks

Encrypted Storage Architecture & LVM Partition Management

Storage Engineering

Challenge: A multi-user workstation and server setup required dynamic disk repartitioning and data-at-rest encryption to comply with strict internal security regulations.
Solution: Re-engineered disk partitioning using LUKS2 full-disk encryption layered underneath Logical Volume Management (LVM). Tuned file system mount flags for performance and quota segregation, and resolved low-level filesystem recovery issues across Btrfs subvolumes in live environments.
Result: 100% data-at-rest protection against unauthorized hardware removal with flexible live storage expansion capabilities.
